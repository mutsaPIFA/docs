# conventions — 팀 공용 컨벤션

모든 레포(`backend` / `frontend` / `ai` / `docs`)·모든 역할이 따르는 공통 규칙.

| 문서 | 내용 |
| --- | --- |
| [브랜치-PR-커밋.md](브랜치-PR-커밋.md) | Git 브랜치 전략(main/dev/feature), PR로 dev 통합, 커밋 메시지 |

> **역할 전용 컨벤션은 해당 역할 레포의 `docs/conventions`에.**
> 예: 백엔드 DTO·예외처리·CI·테스트 → `backend/docs/conventions`, 프론트 컴포넌트·상태관리 규칙 → `frontend/docs/conventions`, AI 프롬프트·모델 규칙 → `ai/docs/conventions`.
> API 응답/에러 형식은 컨벤션이자 계약이라 [`../api-v1.md`](../api-v1.md)에 있음.
